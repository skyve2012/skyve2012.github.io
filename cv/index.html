Agentic & Multi-Agent Systems Research

Independent research program. The through-line: an agent has to be cheap, fast and reliable before it can be multiplied — every call count, communication hop, scheduling decision and failure mode is amplified once several agents, models and tools share a task.

  • Multi-agent architecture search. Work in progress. Building a multi-agent system whose structure is searched rather than hand-designed. Groundwork done — audited the automatic workflow/topology-search literature paper by paper against what each method was really evaluated on: the line sits almost entirely on saturated static benchmarks, and one benchmark name routinely covers several incompatible protocols. Moved the evaluation onto hard agentic benchmarks, against baselines strong enough for the comparison to mean something.
  • Empirical studies of agent collectives. Controlled experiments on independent agents working under identical constraints: convergence scales with constraint strength, and inter-agent visibility produces division of labor rather than new ideas — an empirical read on when multi-agent structure adds value and when it only redistributes it.

Systems & Open Source

  • AutoAgentClaw — a multi-agent optimizer for agent systems: a 12-stage pipeline of specialized agents (discovery, research, strategy, parallel optimization workers, reflection) that reads a target agent repo, finds what is tunable, and improves it level by level, cheapest first — behavior → configuration → inter-agent communication → topology — escalating only on diminishing returns, under tamper-resistant evaluation with a watchdog for reward hacking and score oscillation. Validated end to end on three multi-agent targets (2–3 agents each); the measured gains came from configuration search and from restructuring inter-agent communication. Public, MIT. [Code]
  • lightroom-py — Python library, CLI and agent skill automating Adobe Lightroom Classic, published on PyPI (MIT); a Lua↔Python bridge into a closed desktop application, with a WAL-aware SQLite fast path and ExifTool/XMP fallback. A general-purpose programmatic control layer for Lightroom Classic — a tool built to be driven by an agent, not a human. [PyPI] [Code]
